# just 1.57.0 Contract Sources

This directory vendors the `src/` and `tests/` trees from official just tag
`1.57.0`, commit `e01a6bd7e7a30baf86bc86d2b95b0998ebbdc36f`.

The files are audit inputs only. MoonJust does not compile or execute this Rust
code. `spec-index.txt` and the differential manifest point to exact lines here
so strict coverage can reject missing, stale, or name-only anchors offline.
