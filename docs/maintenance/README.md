# Maintenance Reports

[Wasm migration](WASM_MIGRATION.md) records the active target and validation. `REFACTOR_REPORT.md` is historical and includes the retired Native baseline.

This directory contains reports produced during the maintenance era of the
binary-only MoonJust project. Reports record completed changes, validation
results, compatibility findings, and operational follow-up.

Historical design decisions and reports are kept under
`docs/development/` for context only. They are not current API, release, or
architecture contracts. The current architecture is documented in
`docs/ARCHITECTURE.md`.
