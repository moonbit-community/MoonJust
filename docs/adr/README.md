# Architecture decision records

Architecture decision records capture choices that affect compatibility,
package ownership, host capabilities, public API, or release behavior.

Statuses are `Proposed`, `Accepted`, `Superseded`, or `Rejected`. Accepted ADRs
are changed only by a new ADR that records migration and compatibility impact.
